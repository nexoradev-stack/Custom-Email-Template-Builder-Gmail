## 🪄 A prompt that gives great email code

Whatever your design is made in (Figma, Canva, a screenshot), give it to ChatGPT, Gemini or Claude with:

> Turn this design into an HTML email for Gmail. Use tables for layout (one table row per section), inline CSS, a 600px width, Arial or another web-safe font, and real text (not text inside images). No JavaScript, no external CSS files.

Then upload the real photos and logos with **Edit in preview → Upload**. A screenshot gives the AI the layout, not the image files.
